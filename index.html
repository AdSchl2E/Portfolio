IFCC

IFCC is a C to assembly compiler multi-target (x86-64, ARM64) developed in C++.
It supports a significant subset of the C language, handles basic types, control structures, functions, arrays, structures and performs static analysis to ensure code robustness.
The compiler relies on an Intermediate Representation (IR) for optimization and retargeting.
