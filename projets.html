IFCC

IFCC est un compilateur C vers assembleur multi-cible (x86-64, ARM64) développé en C++.
Il prend en charge un sous-ensemble important du langage C (types de base, structures de contrôle, fonctions, tableaux, structures) et réalise une analyse statique pour garantir la robustesse du code.
Basé sur une Représentation Intermédiaire (IR), il optimise et génère du code assembleur pour plusieurs architectures.

C++ C Python Linux
GitHub
